## Go的特点

| 特点     | 介绍                         |
|:------ |:-------------------------- |
| 高效简洁   | 语法像C语言，写起来像Python语言。开发效率高。 |
| 支持并发   | 天然支持并发任务                   |
| 跨平台支持  | 可以跨平台编译                    |
| 强大的标准库 | 内置HTTP库，可以非常方便的开发Web服务。    |
| 静态类型   | 静态语言，编译器提前检查代码。            |

## Go语言的项目

| 项目          | 介绍                                                                                       |
|:----------- |:---------------------------------------------------------------------------------------- |
| Docker      | Docker 是一个开源的应用容器引擎                                                                      |
| NSQ         | NSQ是一款基于Go语言开发的开源实时分布式消息队列平台，用于高性能、可靠的消息传递和分布式系统构建。                                      |
| Prometheus  | 是一个开源的系统监控与告警工具包，最初由 SoundCloud 开发，并在 2016 年加入 CNCF，主要通过 HTTP 拉取方式采集时序数据并使用 PromQL 进行查询。 |
| CockroachDB | 开源分布式 SQL 数据库                                                                            |
